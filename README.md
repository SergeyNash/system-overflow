# System Overflow

Интерактивный прототип о системном мышлении, ограничениях потока и поведении системы под нагрузкой.

Первый эксперимент визуализирует идею теории ограничений Элияху Голдратта: итоговая скорость системы определяется не самым быстрым участком и не суммой локальных улучшений, а текущим ограничением потока.

## Что внутри

- Живой canvas-граф с узлами, связями, потоками и очередями.
- Эксперимент `01 Узкое место`:
  - подсветка текущего ограничения красным `LIMIT`;
  - фактический поток `v`, предел узла `cap`, очередь `q`;
  - действие `Убрать ограничение` рядом с bottleneck-узлом;
  - терминальный лог событий снизу;
  - перенос ограничения после локальной оптимизации.
- Эксперименты-заготовки:
  - `02 Задержка`;
  - `03 Отсутствующая связь`;
  - свободное исследование.

## Как открыть локально

Проект статический, без сборщика и backend.

Открой `index.html` в браузере или запусти простой локальный сервер из папки проекта:

```bash
python -m http.server 8879
```

Затем открой:

```text
http://127.0.0.1:8879/
```

## Текущий статус

Это ранний интерактивный прототип. Основной фокус сейчас — первый эксперимент про ограничение системы и понятность пользовательского опыта.

Следующие направления развития:

- точнее объяснить расчёт throughput;
- усилить визуализацию очередей и переноса ограничения;
- доработать эксперименты про задержку и отсутствующую связь;
- подготовить архитектуру для пользовательских гипотез и stress-test сценариев.
